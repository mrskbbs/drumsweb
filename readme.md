# Local deployment

## Python (fast & easy)
`python -m http.server -b localhost` - is what i used to serve it locally, but you are free to use whatever you want, cause it's just plain html\css + js

## Jekyll 
1. Follow <a href="https://jekyllrb.com/docs/">jekyll quickstart guide</a>, which describes how to install all of the prerequisites 
2. `bundle exec jekyll serve` in root dir and you're good to go
